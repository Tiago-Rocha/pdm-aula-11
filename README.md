# pdm-aula-11 · Accessibility

Repository for lesson 11 of PDM (Mobile Device Programming), CTeSP DAW, ESTA, University of the Azores, 2026/27.

Tempo Açores from lesson 9, with accessibility problems to fix. In the **Definições** tab there are two test switches: **Letra grande (200%)**, which simulates the largest text size of the phone, and **Mostrar semântica**, which shows what a screen reader (TalkBack, VoiceOver) reads on each part of the screen. Both work in Chrome.

Add `?large=1` to the address in Chrome to open the app with large text, for example `http://localhost:8080/?large=1`.

```bash
git clone https://github.com/Tiago-Rocha/pdm-aula-11.git
cd pdm-aula-11
flutter pub get
```
